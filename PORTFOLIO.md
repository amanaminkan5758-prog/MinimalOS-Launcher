# MinimalOS Launcher - Portfolio Project

## Project Summary
Custom Android launcher untuk smartphone dengan interface minimalis.
**Durasi Development:** 7 hari | **Team Size:** 1 (Solo Developer)

## What I Built
✅ Fully functional Android launcher
✅ Custom Material Design UI
✅ Intent-based app launching (Dialer, WhatsApp, Browser)
✅ Home screen replacement capability
✅ Error handling & edge cases

## Technical Stack
- **Language:** Java
- **Framework:** Android SDK (API 26-34)
- **Build System:** Gradle
- **IDE:** VSCode
- **Version Control:** Git

## Key Achievements
1. **From Zero to Deployment:** Learned Android development & shipped app in 1 week
2. **Architecture:** Clean separation of concerns (layout, logic, resources)
3. **User Experience:** Minimalist design focusing on essential functions
4. **Error Handling:** Graceful handling when apps not installed
5. **Testing:** Comprehensive testing across different scenarios

## Learning Outcomes
- Android Activity lifecycle
- Intent-based navigation
- Layout XML design
- Java programming for Android
- Gradle build system
- App debugging with Logcat
